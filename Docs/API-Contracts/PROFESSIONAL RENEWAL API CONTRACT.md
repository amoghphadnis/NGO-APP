Business Logic Notes:

Base filter:

WHERE Status != 0

Sorting:

ORDER BY PRId DESC

Therefore:

\* Status 0 records are excluded.

\* Results are sorted by PRId descending.

\* Newer/higher PRId records appear first.

Branch Executive filtering:

When:

UserRole == "Branch Executives"

the following additional condition is applied:

AND EXISTS

(

SELECT 1

FROM BranchExecutiveDistrictMapping bedm

INNER JOIN DistrictMaster dm

ON dm.DistrictID = bedm.DistrictID

WHERE bedm.UserId = @UserId

AND dm.DistrictName = ProfessionalRenewal.District

AND ISNULL(bedm.OtherDistrict,'') =

ISNULL(ProfessionalRenewal.OtherDistrict,'')

)

This means:

\* Branch Executives do not receive the unrestricted list.

\* Their results are restricted using BranchExecutiveDistrictMapping.

\* UserID is taken from the authenticated Session.

\* District is matched using DistrictMaster.DistrictName.

\* OtherDistrict is compared using NULL/empty-string normalization.

For users whose UserRole is not "Branch Executives":

No additional UserID/district restriction is added by this controller.
