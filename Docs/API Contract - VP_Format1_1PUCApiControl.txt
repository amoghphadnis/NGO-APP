API Contract - VP_Format1_1PUCApiController
Base Route Prefix: api/VP_Format1_1PUC
1. Get Dropdowns
Endpoint: GET /api/VP_Format1_1PUC/dropdowns
Purpose: Returns dropdown/master data required for the application form.
Name	Type	Required	Description
None	-	-	No parameters
Success Response: Returns Gender, Area, District, Caste, House, Reference, Course, CollegeType, FatherOccupation and MotherOccupation lists.

Business Logic
•	Request must be multipart/form-data.
•	Validates model using DataAnnotations.
•	All five documents are mandatory.
•	Only PDF/JPG/JPEG/PNG files allowed.
•	Creates upload folder automatically.
•	Files stored under /Uploads/PUC_Format1_1/.
•	CreatedDate set using GETDATE().
•	Status defaults to 1.
•	Returns success when record inserted.
