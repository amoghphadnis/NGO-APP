VP_NewProfessional API Contract
Controller: VP_NewProfessionalApiController
Base Route: api/VP_NewProfessional
Endpoint 1 - Get Dropdowns
GET /api/VP_NewProfessional/dropdowns
Purpose: Returns all master dropdown values required to render the New Professional application form.
Content-Type: application/json
Authorization: Not Required
Returns: Gender, Area, District, Caste, House, Reference, Course, CollegeType, FatherOccupation and MotherOccupation lists.

Business Logic
•	Accepts multipart/form-data requests.
•	Creates upload folder automatically if missing.
•	Stores uploaded files under ~/Uploads/NewProfessional/.
•	Files are renamed using GUID values.
•	OtherDistrict saved as NULL when blank.
•	MonthlyRent, CETRank and NEETRank are nullable.
•	CreatedDate is automatically set to DateTime.Now.
•	Status defaults to 1.
•	Returns Success=True after successful database insert.
